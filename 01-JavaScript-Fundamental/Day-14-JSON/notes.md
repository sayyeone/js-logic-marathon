# JSON
Javascript object notation
- format data berbentuk teks/string

ini merupakan object dalam javascript
```js
const student = {
    name: "Dist",
    age: 20,
    skills: ["JavaScript", "HTML"]
}
```

diubah menjadi json yg merupakan string
```js
const studentJSON = `{
    "name": "Dist",
    "age": 20,
    "skills": ["JavaScript", "HTML"]
}`
```
