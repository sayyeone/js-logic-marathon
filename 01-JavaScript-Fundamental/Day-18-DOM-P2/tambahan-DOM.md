## DOM Tree
- nodeList = memilih lebih dari 1 node yg ada
- node = hanya memilih 1 elemen

*contohnya*
```html
<h1>hello</h1>
```

- HTMLCollection = kumpulan node yg khusus elemen HTML aja

**nodeList vs HTMLCollection**
- nodeList dapat berisi node apapun, HTMLCollection harus berisi elemen HTML
- HTMLCollection bersifat live, nodeList tidak

## DOM Selection Method
- getElementById() = element
- getElementsByTagName() = HTMLCollection
- getElementsByClassName() = HTMLCollection
- querySelector() = element
- querySelectorAll() = nodeList
